01-1B

Eigenvalues, Eigenvectors & Diagonalization

Unit 01 CO1 L3 – Apply
Aim
To compute eigenvalues and eigenvectors of a matrix and verify diagonalization.
Theory / Concept
For a square matrix A, scalar λ is an eigenvalue and non-zero vector v is its eigenvector if Av = λv.

Diagonalization: A = P D P⁻¹ where D is diagonal (eigenvalues) and columns of P are eigenvectors.
Python Code
import numpy as np

A = np.array([[4, 1],
              [2, 3]])

# Eigenvalues and eigenvectors
eigenvalues, eigenvectors = np.linalg.eig(A)
print('Eigenvalues:', eigenvalues)
print('Eigenvectors (columns):')
print(eigenvectors)

# Diagonalization: A = P D P^{-1}
P = eigenvectors
D = np.diag(eigenvalues)
P_inv = np.linalg.inv(P)

A_reconstructed = P @ D @ P_inv
print('\nReconstructed A (should match original):')
print(np.round(A_reconstructed, 4))

# Verification: A v = lambda v
for i in range(len(eigenvalues)):
    lam, v = eigenvalues[i], eigenvectors[:, i]
    print(f'\nAv = {A @ v} | lambda*v = {lam * v}')
Expected Output
Eigenvalues, eigenvector matrix, reconstructed matrix A, and verification Av = λv.
Result
Eigenvalues and eigenvectors computed successfully; diagonalization verified.
01-1C

Gaussian Elimination (from Scratch)

Unit 01 CO1 L3 – Apply
Aim
To implement Gaussian Elimination from scratch to solve a system of linear equations.
Theory / Concept
Gaussian elimination transforms the augmented matrix [A|b] to row-echelon form using elementary row operations, then applies back-substitution to find the solution vector x.
Python Code
import numpy as np

def gaussian_elimination(A, b):
    n = len(b)
    # Augmented matrix
    M = np.hstack([A.astype(float), b.reshape(-1, 1).astype(float)])

    # Forward elimination
    for col in range(n):
        # Partial pivoting
        max_row = np.argmax(abs(M[col:, col])) + col
        M[[col, max_row]] = M[[max_row, col]]
        for row in range(col + 1, n):
            factor = M[row, col] / M[col, col]
            M[row] -= factor * M[col]

    # Back substitution
    x = np.zeros(n)
    for i in range(n - 1, -1, -1):
        x[i] = (M[i, -1] - np.dot(M[i, i+1:n], x[i+1:])) / M[i, i]
    return x

A = np.array([[2,  1, -1],
              [-3, -1,  2],
              [-2,  1,  2]])
b = np.array([8, -11, -3])

x = gaussian_elimination(A, b)
print('Solution x:', x)
print('Verification A@x:', np.round(A @ x, 6))
Expected Output
Solution vector x and verification by computing A@x ≈ b.
Result
Gaussian elimination implemented from scratch and system of equations solved correctly.

Binomial & Normal Distributions

Unit 02 CO2 L3 – Apply
Aim
To demonstrate discrete (Binomial) and continuous (Normal) probability distributions using Python.
Theory / Concept
Binomial Distribution — models number of successes in n independent Bernoulli trials with probability p.

Normal Distribution — bell-shaped continuous distribution characterised by mean μ and standard deviation σ.
Python Code
import numpy as np
import matplotlib.pyplot as plt
from scipy.stats import binom, norm

# ── Binomial Distribution ────────────────────────────
n, p = 10, 0.5
x_b = np.arange(0, n + 1)
pmf = binom.pmf(x_b, n, p)

plt.figure(figsize=(12, 5))
plt.subplot(1, 2, 1)
plt.bar(x_b, pmf, color='steelblue', edgecolor='navy')
plt.title('Binomial Distribution (n=10, p=0.5)')
plt.xlabel('Number of Successes')
plt.ylabel('Probability')

# ── Normal Distribution ──────────────────────────────
mu, sigma = 0, 1
x_n = np.linspace(-4, 4, 200)
pdf = norm.pdf(x_n, mu, sigma)

plt.subplot(1, 2, 2)
plt.plot(x_n, pdf, color='crimson', lw=2)
plt.fill_between(x_n, pdf, alpha=0.2, color='crimson')
plt.title('Normal Distribution (mu=0, sigma=1)')
plt.xlabel('x'); plt.ylabel('PDF')

plt.tight_layout()
plt.savefig('distributions.png', dpi=150)
plt.show()

print('Mean (Binomial):', binom.mean(n, p))
print('Variance (Binomial):', binom.var(n, p))
Expected Output
Side-by-side plots of Binomial PMF and Normal PDF; printed mean and variance.
Result
Binomial and Normal distributions demonstrated and plotted successfully.

Joint Probability Mass Function

Unit 02 CO2 L3 – Apply
Aim
To implement and visualize a Joint Probability Mass Function (JPMF) for two discrete random variables.
Theory / Concept
A Joint PMF P(X=x, Y=y) gives the probability that discrete random variable X takes value x AND Y takes value y simultaneously. Marginal distributions are obtained by summing over the other variable.
Python Code
import numpy as np
import matplotlib.pyplot as plt

# Joint PMF table (rows = X values, cols = Y values)
# X in {1,2,3}, Y in {1,2,3}
joint_pmf = np.array([
    [0.10, 0.08, 0.06],
    [0.07, 0.15, 0.10],
    [0.05, 0.12, 0.27]
])

print('Joint PMF Table:')
print(joint_pmf)
print('Sum of all probabilities:', joint_pmf.sum())

# Marginal distributions
marginal_X = joint_pmf.sum(axis=1)
marginal_Y = joint_pmf.sum(axis=0)

print('\nMarginal PMF of X:', marginal_X)
print('Marginal PMF of Y:', marginal_Y)

# Heatmap visualization
plt.figure(figsize=(6, 5))
plt.imshow(joint_pmf, cmap='Blues', aspect='auto')
plt.colorbar(label='Probability')
plt.xticks([0, 1, 2], ['Y=1', 'Y=2', 'Y=3'])
plt.yticks([0, 1, 2], ['X=1', 'X=2', 'X=3'])
plt.title('Joint PMF Heatmap')
for i in range(3):
    for j in range(3):
        plt.text(j, i, f'{joint_pmf[i,j]:.2f}',
                 ha='center', va='center', fontsize=11)
plt.tight_layout()
plt.savefig('joint_pmf.png', dpi=150)
plt.show()
Expected Output
Joint PMF table, marginal distributions, and heatmap visualization.
Result
Joint PMF implemented, marginals computed, and heatmap visualized.

Central Limit Theorem & Probability Distribution Plot

Unit 02 CO2 L3 – Apply
Aim
To demonstrate the Central Limit Theorem (CLT) by plotting the distribution of sample means.
Theory / Concept
CLT states that the distribution of sample means approaches a Normal distribution as sample size n increases, regardless of the population's original distribution.

Standard Error: SE = σ/√n
Python Code
import numpy as np
import matplotlib.pyplot as plt

np.random.seed(42)
population = np.random.exponential(scale=2, size=100000)  # skewed

sample_sizes = [1, 5, 30, 100]
num_samples  = 1000

fig, axes = plt.subplots(1, 4, figsize=(16, 4))
for ax, n in zip(axes, sample_sizes):
    means = [np.mean(np.random.choice(population, n))
             for _ in range(num_samples)]
    ax.hist(means, bins=30, color='steelblue',
           edgecolor='navy', density=True)
    ax.set_title(f'n = {n}', fontsize=13)
    ax.set_xlabel('Sample Mean')
    ax.set_ylabel('Density')

fig.suptitle('Central Limit Theorem — Sample Mean Distributions',
             fontsize=14, y=1.02)
plt.tight_layout()
plt.savefig('clt.png', dpi=150)
plt.show()

print('As n increases, the distribution of sample means becomes Normal.')
Expected Output
Four subplots showing how sample mean distribution converges to Normal as n increases.
Result
CLT demonstrated visually — distribution of sample means normalises with increasing n.
03-3A

Large Sample Test for Single Mean (Z-test)

Unit 03 CO2 L4 – Analyze
Aim
To perform a large sample Z-test for a single population mean and interpret the result.
Theory / Concept
Z-test is used when n ≥ 30.

Test statistic: Z = (x̄ − μ₀) / (σ/√n)

Compare |Z_calc| with Z_critical — 1.96 for α=0.05, 2.576 for α=0.01.
If |Z_calc| > Z_critical → reject H₀.
Python Code
import numpy as np
from scipy import stats

# Given data (Problem: diesel engine thermal efficiency)
mu_0  = 32.5   # claimed mean (H0)
x_bar = 31.4   # sample mean
sigma =  1.6   # population std dev
n     =    40   # sample size
alpha =  0.01  # level of significance

# Z test statistic
Z_calc = (x_bar - mu_0) / (sigma / np.sqrt(n))
print(f'Z_calculated = {Z_calc:.4f}')

# Critical value (two-tailed)
Z_crit = stats.norm.ppf(1 - alpha / 2)
print(f'Z_critical (two-tailed, alpha={alpha}) = {Z_crit:.4f}')

# Decision
if abs(Z_calc) > Z_crit:
    print('Decision: REJECT H0 — Claim is NOT acceptable')
else:
    print('Decision: FAIL TO REJECT H0 — Claim is acceptable')

# p-value
p_value = 2 * (1 - stats.norm.cdf(abs(Z_calc)))
print(f'p-value = {p_value:.6f}')
Expected Output
Z_calculated, Z_critical, decision statement, and p-value.
Result
Z-test performed; H₀ rejected at 0.01 LOS — the company's claim is not supported.

n-Step Transition Probability

Unit 04 CO3 L3 – Apply
Aim
To calculate n-step transition probabilities for a Markov chain using matrix exponentiation.
Theory / Concept
For a Markov chain with transition matrix P, the n-step transition probability P⁽ⁿ⁾ = Pⁿ (matrix power).

P⁽ⁿ⁾ij gives the probability of moving from state i to state j in exactly n steps.
As n→∞, Pⁿ → steady-state matrix.
Python Code
import numpy as np

# Transition matrix
P = np.array([[0.5,  0.5],
              [0.75, 0.25]])

# Initial distribution
P0 = np.array([0.25, 0.75])

def matrix_power(M, n):
    result = np.eye(len(M))
    for _ in range(n):
        result = result @ M
    return result

# 2-step transition matrix
P2 = matrix_power(P, 2)
print('P^2 (2-step transition matrix):')
print(np.round(P2, 4))

print(f'\nP^2_21 (state 2->1 in 2 steps): {P2[1,0]:.4f}')
print(f'P^2_12 (state 1->2 in 2 steps): {P2[0,1]:.4f}')

# Distribution after n steps
for n in [1, 2, 5, 20]:
    dist = P0 @ matrix_power(P, n)
    print(f'Distribution after {n:2d} steps: {np.round(dist, 4)}')

# Steady state
P_inf = matrix_power(P, 200)
print('\nSteady-state (P^200):')
print(np.round(P_inf, 4))
Expected Output
2-step matrix, specific transition probabilities, state distributions, and steady-state.
Result
n-step transition probabilities computed; steady-state distribution identified.
05-5C

Simple Linear Regression on a Real Dataset

Unit 05 CO4 L3 – Apply
Aim
To perform Simple Linear Regression on a real dataset and visualize the regression line.
Theory / Concept
SLR models the relationship Y = β₀ + β₁X + ε.

Normal equations: β₁ = Σ(xᵢ−x̄)(yᵢ−ȳ) / Σ(xᵢ−x̄)², β₀ = ȳ − β₁x̄

R² measures goodness of fit (closer to 1 = better fit).
Python Code
import numpy as np
import matplotlib.pyplot as plt
from sklearn.linear_model import LinearRegression
from sklearn.datasets import load_diabetes
from sklearn.metrics import r2_score, mean_squared_error

# Load real dataset (diabetes — single feature: BMI)
data = load_diabetes()
X = data.data[:, 2].reshape(-1, 1)  # BMI feature
Y = data.target

# Fit model
model = LinearRegression()
model.fit(X, Y)
Y_pred = model.predict(X)

print(f'Intercept (b0)  : {model.intercept_:.4f}')
print(f'Coefficient (b1): {model.coef_[0]:.4f}')
print(f'R-squared       : {r2_score(Y, Y_pred):.4f}')
print(f'RMSE            : {np.sqrt(mean_squared_error(Y, Y_pred)):.4f}')

# Plot
plt.figure(figsize=(8, 5))
plt.scatter(X, Y, color='steelblue', alpha=0.5, label='Actual data')
plt.plot(X, Y_pred, color='crimson', lw=2, label='Regression line')
plt.xlabel('BMI (normalised)')
plt.ylabel('Disease Progression')
plt.title('Simple Linear Regression — Diabetes Dataset')
plt.legend()
plt.tight_layout()
plt.savefig('slr.png', dpi=150)
plt.show()
Expected Output
Regression coefficients, R², RMSE, and scatter plot with regression line.
Result
Simple Linear Regression applied successfully; regression equation and fit metrics reported.

Lagrange's Interpolation Method

Unit 06 CO4 L3 – Apply
Aim
To implement Lagrange's Interpolation formula and estimate the value of a function at a given point.
Theory / Concept
Lagrange's formula: P(x) = Σ yᵢ × ∏j≠i (x−xⱼ)/(xᵢ−xⱼ)

It passes exactly through all given data points and requires no equal-spacing assumption.
Python Code
import numpy as np
import matplotlib.pyplot as plt

def lagrange_interpolate(x_points, y_points, x):
    """Return interpolated value at x using Lagrange's formula."""
    n = len(x_points)
    result = 0.0
    for i in range(n):
        term = y_points[i]
        for j in range(n):
            if j != i:
                term *= (x - x_points[j]) / (x_points[i] - x_points[j])
        result += term
    return result

# Given data points
x_pts = np.array([1,  3,  7, 13], dtype=float)
y_pts = np.array([2,  5, 12, 20], dtype=float)

# Estimate at x = 4
x_est = 4
y_est = lagrange_interpolate(x_pts, y_pts, x_est)
print(f'Lagrange interpolated value at x={x_est}: y = {y_est:.4f}')

# Plot the polynomial
x_range = np.linspace(1, 13, 300)
y_range = [lagrange_interpolate(x_pts, y_pts, xi) for xi in x_range]

plt.figure(figsize=(8, 5))
plt.plot(x_range, y_range, 'b-', lw=2, label='Lagrange Polynomial')
plt.scatter(x_pts, y_pts, color='red', s=80, zorder=5, label='Data Points')
plt.scatter(x_est, y_est, color='green', s=120, marker='*', zorder=6,
           label=f'Interpolated ({x_est}, {y_est:.2f})')
plt.xlabel('x'); plt.ylabel('y')
plt.title("Lagrange's Interpolation")
plt.legend()
plt.grid(True)
plt.tight_layout()
plt.savefig('lagrange.png', dpi=150)
plt.show()
Expected Output
Interpolated value at x=4 and plot of the Lagrange polynomial through data points.
Result
Lagrange Interpolation implemented; interpolated value obtained and polynomial plotted.
